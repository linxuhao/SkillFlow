# SkillFlow 1.5.100 — tool checkpoint ordering

Tool steps now honor `checkpoint: true` when an unconditional or ordinary
result-matching edge selects the next node. The completed tool's retained
checkpoint is exposed before any successor runs or its target end condition
finishes the pipeline. The special approval-guarded edge remains supported.

The change reuses the existing checkpoint identity, explicit decision and
replay protocol. It does not introduce graph syntax or an automatic decision.
Noncheckpoint continuation, failed-tool routing and existing terminal-step
semantics remain unchanged. Regression tests use real ToolLoader callbacks,
including rejection, stale identities, exact replay and consecutive checkpoints.

This source preparation does not imply publication, installation or AItelier
backend activation; those require their own measured release/runtime records.
