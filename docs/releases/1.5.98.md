# SkillFlow 1.5.98 — Source preparation

Restore ordinary checkpoint review for the exact retained historical prefixed-only
pause schema. A first valid legacy read durably appends one fresh modern binding,
with original event id/raw SHA256 and explicit newly derived provenance; it leaves
original bytes, retained outputs, run status and execution unchanged. Modern reads
stay read-only. Pinned history, route, execution, stale output and decision replay
checks remain strict. Supported repins after the old pause refuse binding, even
before first read or back to the same pin. Repin event persistence is now atomic
with its graph update, before asynchronous notifications.

Version 1.5.98 was unused on PyPI and absent from official Git tags at preparation.
Author tests are UNRUN. Independent exact-SHA review and container execution,
publication, installation and host activation are separate operations.


The Source repair protects transaction finalization as well as its body: COMMIT
errors roll back before they propagate. A failed legacy binding cannot remain
visible only on the writer's open transaction and become usable on ordinary
get_checkpoint retry. Intentional _TxRollback still aborts silently; normal
commits, modern read-only checkpoints and atomic repin events retain their
contracts. The real deferred-constraint regression was committed before this
correction; it verifies transaction cleanup, an independent connection's persisted
rows, no retry token while the fault remains, and useful retry after fault removal.
The prior INSERT-time refusal did not observe COMMIT-time durability. Author
tests remain UNRUN; the preceding independent failure is retained separately.
