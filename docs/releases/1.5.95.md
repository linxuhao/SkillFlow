# SkillFlow 1.5.95 — required artifact content

Generated fixed artifact create/write calls reject omitted or null content with
an actionable tool error, preserving existing files and archive names. Explicit
empty text remains supported for fixed text slots. JSON document validation,
edits, finish, publication and receipt/recovery semantics remain unchanged.
Declared append writes and generic whole-file writes also enforce their required
content argument.

The regression controls use actual generated schemas, native dispatch and owned
claims, including absent and existing targets, correction, edit and publication.
This private release preparation is not publication, host pinning or deployment.
