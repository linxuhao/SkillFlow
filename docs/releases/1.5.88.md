# SkillFlow 1.5.88

A successful apply_patch echo shows enough of the file around each edit to
skip the next read: up to 20 unchanged lines on each side of every echoed
block (was 1), and a touched range is shown whole up to 80 lines (was 40),
beyond which its first 40 and last 40 lines are shown. Citations still cover
exactly the shown lines, so an edit inside the new context needs no read and
one beyond it is refused. tool.yaml and README say the echo is the file as it
now reads and to read only for lines it does not show.

Measured over recorded AItelier steps since 1.5.83: of the first read of a
file after its echo, 1% asked only for lines the echo had shown and 55-62%
asked for the echoed lines plus more around them (median 11-18 extra lines,
p75 26-43); the context needed did not grow with the size of the edit.
Replayed against the new geometry, 44% (DeepSeek V4.1-Flash) and 49%
(GLM-5.3-Flash) of those reads fall entirely inside the echo - an upper bound
on reads avoided, to be measured after deployment.
